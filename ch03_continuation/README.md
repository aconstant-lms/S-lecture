## Planned content
- Following a branch: natural parameter, pseudo-arclength (Keller), Riks and Crisfield arc-length.
- Detecting and classifying critical points along a branch; branch switching.
- From the weak form to the discrete problem: tangent stiffness, linear buckling as an eigenproblem.
- Tools: a continuation code in Python written from scratch, FEniCS (with SLEPc) and Cast3M (PASAPAS, VIBR), all checked first on the discrete models of Chapter 2.
- Asymptotic numerical method as an alternative to predictor-corrector schemes.
